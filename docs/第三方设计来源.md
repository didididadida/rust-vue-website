# 第三方设计系统来源说明

本项目的前端视觉参考了 **Valaxy** 的设计系统。本文记录具体来源与改动范围，
用于满足 MIT 协议的署名要求，也便于后续升级时对照上游。

## 上游项目

| 项 | 值 |
|---|---|
| 项目 | Valaxy |
| 仓库 | <https://github.com/YunYouJun/valaxy> |
| 作者 | YunYouJun 及贡献者 |
| 协议 | MIT License |
| 版本参考 | `main` 分支（2026-11 读取） |
| Star 数 | 1128（读取时） |

Valaxy 是一个基于 Vue 3 + Vite 的静态博客框架。本站没有使用它的框架，
只**照抄了它的设计 token 与页面结构**。

## 具体照抄的文件

| 上游文件 | 本站对应 | 照抄内容 |
|---|---|---|
| `packages/valaxy-theme-press/styles/tokens.css` | `frontend/src/style.css` | 全部颜色变量（`--press-c-*`） |
| `packages/valaxy-theme-press/styles/css-vars.scss` | `frontend/src/style.css` | 尺寸、字体、缓动、z-index 变量（`--pr-*`） |

| `packages/valaxy-theme-press/components/PressHomeFeatures.vue` | `frontend/src/views/Home.vue` | 特性区三栏结构 |

### 入场动效

```css
@keyframes press-enter {
  from {
    opacity: 0.01;
    transform: translateY(var(--pr-enter-distance));
  }
}

@media (prefers-reduced-motion: no-preference) {
  .press-enter {
    animation: press-enter var(--pr-duration-enter) var(--pr-ease-out) both;
    animation-delay: calc(var(--pr-enter-order, 0) * 70ms);
  }
}
```

**为什么从 `0.01` 而不是 `0` 开始**：上游源码注释说明——
动画元素若起始 `opacity: 0`，会被排除在 LCP（Largest Contentful Paint）
候选之外，导致性能指标测不到真实的首屏内容。从 `0.01` 开始可保持其为 LCP 候选。

## 本站的改动

为了让设计系统适配本站，做了以下偏离，均已在代码注释中标注：

| 项 | 上游 | 本站 | 理由 |
|---|---|---|---|
| 品牌色 | `#a8b1ff`（靛蓝） | `#4cc9f0`（青） | 站点已有品牌色，保持一致性 |
| Hero 右侧视觉 | `PressHomeOrbit`（canvas 轨道动画） | 文章统计环 | 上游动画需独立 canvas，且与本站背景重复 |
| 主题切换 | 支持明暗切换 | 固定暗色 | 站点定位为暗色设计 |
| 站点名 | 来自 frontmatter | 硬编码在组件 | 本站无 SSG，无 frontmatter |

**未改动的部分**：所有颜色灰阶、尺寸、缓动曲线、断点（900px / 600px）均与上游一致。

## 未照抄的上游模块

以下上游能力**没有**移植，因为它们依赖 Valaxy 的框架层：

| 模块 | 依赖 | 说明 |
|---|---|---|
| `PressHomeOrbit` | canvas 绘制 | 轨道动画，需独立绘制逻辑 |
| `PressSidebar` / `PressAside` | Valaxy 路由与侧边栏数据 | 本站侧边栏在 `App.vue` 中手写 |
| `PressSearchButton` | 本地索引（fuse.js） | 本站暂未实现站内搜索 |
| `PressNavBarTranslations` | vue-i18n | 本站为中文单语言 |
| `PressSwitchAppearance` | 明暗切换 | 本站固定暗色 |
