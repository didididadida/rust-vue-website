Open Source Project

Rust + Vue 网站项目

一个不依赖数据库 ORM、不引入 UI 组件库的个人博客系统。 文章存 Markdown 文件，评论存 JSON，上传记录存 SQLite。

Rust 1.85+ actix-web 4 Vue 3 Vite 5 MIT License
查看源码 在线演示

核心功能

只做博客需要的事，不加多余的东西

📝 Markdown 写作

文章即文件。YAML front matter 记录标题、分类、标签，正文用标准 Markdown，可直接用任意编辑器打开。

✏️ 全屏纯文本编辑

后台可直接编辑整个 .md 文件含元数据块，保存前校验 YAML，格式错误拒绝写入，不会写坏文章。

💬 嵌套评论

支持多级回复、待审核队列、B 站风格编辑器，可直接粘贴截图自动上传。

🖼️ 内置图床

图片无损重编码，支持粘贴与拖拽上传，上传记录用 SQLite 索引，按上传者筛选。

🔐 JWT 认证

bcrypt 密码哈希、邮箱验证码注册、登录失败限速（用户名 + IP 双维度）。

📊 行内编辑后台

文章表格支持直接改别名、分类、切换发布状态，批量删除，无需逐个打开弹窗。

架构

前后端分离，静态资源与 API 分离部署

存储

Markdown 文件
JSON 文件

↓ Nginx 反代 /api/ 与 /static/ ↓
内容位置为什么
文章posts/*.md单人低频写，要人能直接看、要能 Git 版本化
评论data/comments/<slug>.json每篇一个数组，无需数据库
上传记录data/wanle.db高频写，需按上传者筛选，索引比遍历目录快
用户data/users.txt一行一个，安全敏感、格式稳定

快速开始

需要 Rust 1.85+ 与 Node.js 18+

1. 配置
cp .env.example .env
# 至少设置 JWT_SECRET；ADMIN_PASSWORD 留空则随机生成
2. 启动后端
cd backend-rust
cargo run
# http://127.0.0.1:8000
3. 启动前端
cd frontend
npm install
npm run dev
# http://127.0.0.1:5173，/api 自动代理到 8000
4. 生产构建
cd frontend && npm run build
cd ../backend-rust && cargo build --release
